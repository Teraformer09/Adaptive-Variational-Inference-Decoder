# BM2: V0 Offline World-Model & LoRA Architectural Ablation (`A0..A7`)

> **Scope Notice (Finding 10 Resolution)**: This V0 benchmark evaluates 8 offline Python/PyTorch model variants (`A0` Static Uniform BP through `A6` Full AVID R2D2-Graph-RSSM + Rank-4 LoRA and `A7` Oracle Floor) on synthetic syndrome streams. It is distinct from the **V1 6-Way C++ Runtime & RTL Decoder Ablation** (`reports/v0/closure/v0_closure_40_40_report.json`), which evaluates the 64-unit `int8` LSTM R2D2-WB controller (`software/src/control/r2d2_lstm_controller.h`) and hardware OSD modes (`cfg_osd_mode = 0, 1, 2`) inside `avid_daemon`.
