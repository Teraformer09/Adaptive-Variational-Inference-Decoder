# World Model Architecture, Non-Vision Graph Perception, and R2D2 Partial-Observability Memory

## 1. Observation Contract and Non-Vision Quantum Graph Perception

Classical world models developed for visual reinforcement learning rely on two-dimensional convolutional neural networks (CNNs) or Vision Transformers (ViTs) to compress dense pixel grids into latent vectors. In contrast, observations generated by a superconducting quantum processor during repeated stabilizer cycles are non-visual, sparse, and multi-modal signals defined over a versioned bipartite processor topology $G = (V, E)$ comprising data qubits, ancilla stabilizer checks, and tunable coupler edges. At each syndrome-extraction round $t$, the world model receives only experimentally observable quantities $o_t = (d_t, s_t, c_t, a_t, u_t, G)$: sparse binary detection events $d_t$, raw stabilizer parity outcomes $s_t$, periodic calibration telemetry $c_t$, optional soft analog readout log-likelihood ratios $a_t$, and the active circuit schedule $u_t$. Simulator-only ground truth (`latent_truth`) is strictly excluded from all inference calls.

To encode $o_t$ without pixel-based assumptions, the `QuantumGraphPerceptionEncoder` processes inputs through four physics-informed feature stems before executing spatial message passing. First, a discrete syndrome stem embeds binary detection events, raw parity outcomes, and topological node roles ($X$-check vs. $Z$-check). Second, a validity-masked analog and telemetry stem projects continuous readout LLRs and calibration measurements via explicit mask concatenation $[m_{i,t} \odot x_{i,t},\, m_{i,t}]$, guaranteeing that missing measurements never alias with numerical zero. Third, a two-dimensional chip-geometry stem expands pairwise Euclidean distances $d_{ij} = \|\mathbf{r}_i - \mathbf{r}_j\|_2$ across Gaussian radial basis functions (RBFs) so the encoder natively resolves radially decaying acoustic phonon bursts (`A2`). Fourth, a schedule-conditioned edge stem injects active gate types, Rabi drive amplitudes, and parallel concurrency groups $u_t$ onto coupler and spectator edges (`A1`). These node and edge representations are then fused across the processor graph using either edge-conditioned message passing (`GATv2`) or edge-biased multi-head graph attention.

## 2. Factored Physical Latent Space and Dual-Backbone Memory under Partial Observability

Quantum hardware noise estimation is a severely partially observable problem: a single silent stabilizer round cannot distinguish a nominal qubit from a transmon trapped in a $|2\rangle$ leaked state (`B1`) or a coherent TLS defect undergoing a temporary dephasing revival (`C1/C2`). Rather than compressing history into an uninterpretable monolithic vector, the world model factors its stochastic latent state $z_t$ into five typed physical subspaces: schedule-conditioned correlated crosstalk (`z_corr`), multi-level transmon leakage (`z_leak`), slow calibration drift (`z_drift`), non-Markovian TLS and bath memory (`z_memory`), and chip-wide common-mode burst disturbances (`z_event`).

To evaluate recurrent state-space tracking against sequence attention under identical parameter budgets, the architecture supports two interchangeable temporal backbones sharing the same perception layer and latent bottleneck. **Version A (`R2D2-Graph-RSSM`)** integrates the partial-observability memory mechanisms of Recurrent Experience Replay (R2D2) into a Variational Recurrent State-Space Model. Specifically, it pairs a dual-timescale recurrent core $(h_t, c_t)$—initialized via Chrono-Initialization so forget-gate biases span characteristic relaxation timescales from $T_{\min}=1$ round to $T_{\max}=96$ rounds—with R2D2 stored-state burn-in warmup (`burn_in_steps = 16`). Rolling the recurrent core through the initial burn-in window under `torch.no_grad()` warms up the internal belief state from real syndrome history before backpropagation begins, eliminating cold-start blindness when leakage or TLS drift episodes start prior to the training window. **Version B (`Small Spatio-Temporal Causal Transformer`)** replaces explicit recurrent updates with causal multi-head self-attention over the round history, using the initial burn-in window as causal context warmup before projecting into the five variational latent distributions.

## 3. Six Physics Prediction Heads and Variational ELBO Objective

From the posterior belief state $b_t = (h_t, c_t, z_t)$ and the known future gate schedule $u_{t+1:t+H}$, the world model unrolls its transition prior $p_\theta(z_t \mid h_t, u_t)$ across forecast horizons $H \in \{1, 2, 4, 8\}$ and decodes six specialized prediction heads: (1) per-check detection-event probability, (2) schedule-conditioned pairwise fault correlation, (3) per-transmon $|2\rangle$ leakage probability, (4) slow OU drift and non-Markovian TLS memory revival rate, (5) masked calibration telemetry reconstruction, and (6) chip-wide burst probability and spatial phonon footprint.

Training optimizes a multi-task sequential variational objective combining observation negative log-likelihood $\mathcal{L}_{\mathrm{obs}}$, free-nats regularized posterior-to-prior Kullback–Leibler divergence $\beta D_{\mathrm{KL}}\!\left[q_\phi(z_t \mid h_t, g_t) \,\|\, p_\theta(z_t \mid h_t, u_t)\right]$, simulator-only auxiliary physical mechanism supervision $\mathcal{L}_{\mathrm{aux}}$ (active only during offline training), and multi-step predictive forecast likelihood $\mathcal{L}_{\mathrm{forecast}}$ across horizons $H \in \{1, 2, 4, 8\}$.
